# Attic Minecraft Launcher v0.0.10 — 社区服务器列表页 + 首启向导补强 + 进服匹配定稿（试装轨 prerelease）

专注远古 Minecraft（Pre-Classic → b1.7.3/1.5.2 区间）的桌面启动器。本版为 v0.0.9 的增量试装版，核心是**社区服务器列表页全链**——Betacraft 联机服从此在启动器内直接浏览与进服；外加**首启向导补强**（微软登录入口 + Java 候选点选/目录指定）与一批体验修复。**静默自动更新通道自 0.1.0 stable 起才开放**，0.0.x 用户请从 Releases 页手动下载新版安装器，覆盖安装即升级（数据 `.attic` 原样保留）。构件矩阵与壳定位同 v0.0.2–v0.0.9（见对应页说明）。

## 新增：社区服务器列表（Betacraft Server List）

- 服务器页接入 **BC legacy_server_list 单源**：在线服务器直接列出（名称/地址/协议/推荐版本），点选即可进服。
- **协议区间筛选**：按服务器 `join://` 协议的协议值圈定兼容版本全集，版本选择器只列可用区间；协议外服务器提示手动选版本。
- **进服前置双轨 mod 匹配**：官方轨 + Mods 仓库轨（含远端 `getmods.jsp` 仓库全名三级匹配），确认进服时命中项自动入库——复古 mod 服（如 UberBukkit 类客户端）不再需要手动装基座。
- **匹配语义定稿**：v1 `getMod` 原样精确直命中**前置官方轨**（实案：`Uberbukkit Client a1.2.6` 不再被归一原版 `a1.2.6` 抢走）；前缀匹配加**数字边界闸**（实案：`1.12.2` 不再误配 `1.1`，合法形态 `b1.7→b1.7.3` 全保住）。

## 新增：首启向导补强

- 步骤 2 账户页新增**微软账户登录**入口（与账户页同款设备码弹窗），正版玩家首启即可落账。
- 步骤 3 Java 页新增**候选列表点选**（对齐设置 → Java 的探测报告）与**指定目录**：未列出时直接指 JDK 目录，启动器自行解析 `bin/java`，不再要求手挑 exe。

## 体验修复与健壮性

- 侧栏**首启默认折叠**（rail 形态）；已存偏好原样尊重。
- 直连询问弹窗补**显式取消钮**，无需先走一遍单人启动才能退出。
- 微软登录弹窗**防误关**（点遮罩不丢设备码流程）。
- **控制台窗随主窗退**：主窗口关闭时控制台窗连带关闭，根治控制台独活撑住进程、在跑游戏却无 UI 可终止的死角。
- 关窗看门狗触发面扩展：非 Applet 直连服挂 LWJGL 窗类，关游戏窗即回收空转 java 进程。
- 关于页**版权声明修复**：法务行占位补名（Copyright © 2026 CreatorCSIE），页头版权行与法务行标题键分离。

## 兼容面

- 契约新增 `attic:servers:list` 请求通道（双壳镜像同步，通道总数 45 请求 + 5 事件），向后兼容。
- 新增 `ServerListView` 视图类型（`join://` 四段解析产物 + `compatibleVersionIds` 协议兼容全集 + `matchedModInfoUrl` 命中仓库条目）；`VersionRef` 新增可选 `protocol` 字段。
- 设置 `javaPath` 支持 **JDK 目录形态**（至多两层解析 `bin/java`；目录内无 java 显式报错、不回落自动探测），exe 路径形态行为不变。

## 已知边界

- 服务器列表单源 = Betacraft legacy_server_list，源外服务器仍走手动添加/直连。
- 匹配边界闸只拦「数字延续」误配形态；语义相近但命名不同的条目仍需手动选版本。
- 静默自动更新自 0.1.0 stable 起开放；Linux / macOS 为 Tier-2。
- 试装构件：遇到问题欢迎在仓库 Issues 反馈——请附「控制台」页日志或 `launcher/logs/output-client.log` 与版本号。
