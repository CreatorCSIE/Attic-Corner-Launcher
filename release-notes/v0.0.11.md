# Attic Minecraft Launcher v0.0.11 — Intel 显卡修复开关 + 出站 UA 统一 + 代码扁平化（试装轨 prerelease）

专注远古 Minecraft（Pre-Classic → b1.7.3/1.5.2 区间）的桌面启动器。本版为 v0.0.10 的增量试装版，核心是**实例 Addons 卡新增「Intel 显卡修复」开关**与**全部出站请求统一携带启动器 UA**，外加一轮**代码扁平化**（死码清理 + 注释压缩，行为零变化）和分发文档面收口。**静默自动更新通道自 0.1.0 stable 起才开放**，0.0.x 用户请从 Releases 页手动下载新版安装器，覆盖安装即升级（数据 `.attic` 原样保留）。构件矩阵与壳定位同 v0.0.2–v0.0.10（见对应页说明）。

## 新增：Intel 显卡修复开关（-Dlf.intel）

- 实例 Addons 卡新增第 10 个实装项 **「Intel 显卡修复」**：勾选后启动时注入 `-Dlf.intel`，由 legacyfix `IntelGraphicsPatch` 在老 Intel GPU 上于 `glActiveTexture` 前补发 `glClientActiveTexture`，修复多纹理渲染错乱（b1.9–1.7.10）。
- **opt-in 默认关**：不勾选行为与旧版完全一致；区间外版本该属性无感（沿用 legacyfix 原生语义，启动器不做版本判断）。

## 新增：出站 User-Agent 统一

- 启动器**全部出站请求**（版本清单/版本 JSON/资产下载、客户端 jar、Zulu Java、微软登录、GitHub 检查更新）统一携带 `Attic/<版本号>` UA——GitHub API 缺 UA 一律 403 的硬要求提前兜住，多路下载被 CDN 区别对待的排查成本掐掉。
- 注入点在运行时网络层单点收口，三壳（Tauri/Electron/Win7 兜底）同享；已自带 UA 的请求保留原值不覆盖。

## 代码扁平化（内部质量，无用户可见变化）

- 死代码清理：零引用导出与 13 个死 i18n 键三语同步删除（动态键逐一复核在用、保留）。
- 注释压缩：历史叙事剥壳为现状说明，陷阱与不变量注释原文保留；11 处失同步注释以代码为准勘正。
- 行为零变化经多重集对比核验，全闸门（类型/构建/测试/契约镜像/API 锁）绿。

## 文档面收口

- README FAQ 补全分发文档面：**Linux 已知问题清单**（Q7.5 扩为四条，新增 WebKitGTK DMABUF 黑屏与 Wayland 会话的环境变量逃生舱）+ **macOS 未签名构件「右键打开」教程**（新增 Q5.6）。

## 兼容面

- **零 IPC 契约变更**（通道总数仍 45 请求 + 5 事件），三壳与数据目录布局不动。
- 实例档案 `addons` 键新增可选项 `intel`（enable 族）；旧档案无该键 = 默认关，行为不变。

## 已知边界

- 「Intel 显卡修复」仅在 legacyfix `IntelGraphicsPatch` 生效区间（b1.9–1.7.10）内有意义；区间外勾选无效果亦无害。
- 静默自动更新自 0.1.0 stable 起开放；Linux / macOS 为 Tier-2。
- 试装构件：遇到问题欢迎在仓库 Issues 反馈——请附「控制台」页日志或 `launcher/logs/output-client.log` 与版本号。
