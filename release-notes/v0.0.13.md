# Attic Corner Launcher v0.0.13 — 品牌更名 + 自有 AppID 换绑（待审批）+ 服务器列表范围外解释态（试装轨 prerelease）

专注远古 Minecraft（Pre-Classic → b1.7.3/1.5.2 区间）的桌面启动器。本版为 v0.0.12 的增量试装版，核心是**品牌更名**、**自有 AppID 换绑**与**社区服务器列表的版本范围外体验重做**。**静默自动更新通道自 0.1.0 stable 起才开放**，0.0.x 用户请从 Releases 页手动下载新版安装器，覆盖安装即升级（数据 `.attic` 原样保留）。构件矩阵与壳定位同 v0.0.2–v0.0.12（见对应页说明）。

## 品牌更名：Attic Corner Launcher

- 产品名从 "Attic Minecraft Launcher" 更名为 **"Attic Corner Launcher"**（阁楼角落，收存旧时光之意）。依据 Mojang 应用审批规范，产品名称不得包含 Minecraft 等字样；本次更名覆盖界面标题、安装器显示名、构件命名（前缀 `amcl-*` → `attic-*`）与仓库地址（旧仓库名自动重定向）。
- 数据目录 `.attic`、应用标识 `uk.attic.launcher`、包名 `@attic/*` **均不变**，覆盖安装数据原样保留；可执行文件名随更名变化，**本版建议手动下载新安装器安装一次**（而非依赖旧构件自更新）。

## 微软登录：自有 AppID 换绑（待审批）

- 微软登录缺省通道从借用 Betacraft 社区的临时通道**切换为自有 AppID**（新注册已提交 Mojang 第三方启动器白名单审批，**周审节奏，批准后即生效、无需更新启动器**）。此前因临时通道凭据被吊销而反复掉登录的问题，根源治理了一层。
- ⚠️ **审批落地前微软登录暂不可用**（登录末段返回 403）——**离线账户完全不受影响**，可用版本下载与游戏照常；在设置里自定义过 `microsoftClientId` 的用户走自己的通道。
- ⚠️ **既有微软账户需要重新登录一次**：登录凭据与旧通道绑定，换绑后无法静默续期（启动器会提示重新走一次微软登录，约 30 秒）。

## 社区服务器列表：范围外服务器不再误导

- **超出支持版本范围的服务器**（如 1.6+ 现代服）此前点「加入游戏」会弹出一个误导性的版本选择窗（列表里全是进不去的版本）——现在改为**解释态**：明示「该服务器要求的版本与协议」，提供**复制服务器地址**按钮（可拿去其他启动器使用），不再展示必然握手失败的可选项。
- 上游数据自相矛盾的服务器（协议段与版本名对不上，如部分 1.21.x 代理服）同样落入解释态，且把矛盾数据原样展示给用户可见。
- 版本名只差连字符/下划线的服务器（如 `b1.9pre6` ↔ `b1.9-pre6`）现在能正确自动匹配并预选可玩版本。
- 列表展示面不变：所有服务器照常可见可收藏，仅「进服」动作对范围外服务器改为解释。

## 兼容面

- **零 IPC 契约变更**（通道总数仍 45 请求 + 5 事件），三壳与数据目录布局不动。
- 服务器列表新增派生字段为纯增量可选键，旧构件行为不回退。

## 已知边界

- 静默自动更新自 0.1.0 stable 起开放；Linux / macOS 为 Tier-2。
- 服务器列表「进服」仍要求所选实例版本与服务器握手兼容——本启动器定位远古区间（Pre-Classic → b1.7.3/1.5.2），现代版本服务器请使用其他启动器（解释态的复制地址即为此准备）。
- 试装构件：遇到问题欢迎在仓库 Issues 反馈——请附「控制台」页日志或 `launcher/logs/output-client.log` 与版本号。
